# E-Commerce AI Insights



An AI-powered business intelligence tool for small e-commerce businesses.



## What it does

Ingests sales data, runs statistical analysis, and generates plain-English insights 

using AI — so a business owner can understand what's working and what's losing money.



## Tech stack

- Python

- pandas

- SQL

- OpenAI / Anthropic API (coming soon)



## Project structure

ecommerce-ai-insights/

├── data/          # raw and cleaned datasets

├── src/           # core Python modules

├── notebooks/     # exploratory analysis

└── docs/          # write-ups and methodology
